# Kundali: वर-वधू कुंडली मिलान का सांख्यिकीय विश्लेषण

यह रिपॉज़िटरी एक वर-वधू जोड़े (दिनेश और पी) के कुंडली मिलान की गणना करती है, और लाखों रैंडम कुंडलियों से तुलना करके बताती है कि कोई संयोग कितना कम बनता है।

- ग्रह-स्थिति: [Swiss Ephemeris](https://www.astro.com/swisseph/) (`pyswisseph`), लाहिड़ी अयनांश
- दिनेश और पी की ग्रह-स्थितियाँ जगन्नाथ होरा की तालिका से ली गई हैं (`sanyog_sim.py`, `sabhi_bindu.py`)
- दशकूट के अंक Parashara's Light (कालप्रकाशिका विधि) की रिपोर्ट से मिलाए गए हैं

## चलाने का तरीका

```bash
pip install -r requirements.txt   # कूट मिलान वाली फ़ाइलें (dashakoot_44, dashakoot_enum, sabhi_bindu) इसके बिना भी चलती हैं
python antim_milan.py        # सभी मुख्य कसौटियाँ एक साथ, दिनेश स्थिर, २ लाख वधुएँ
python dashakoot_44.py       # दशकूट ४४ अंक, सभी १०८ x १०८ नक्षत्र-चरण
```

जड़ (root) की **हर `.py` फ़ाइल अकेले चलती है।** किसी भी एक फ़ाइल को कहीं भी कॉपी करके चलाया जा सकता है; उसे दूसरी फ़ाइल की ज़रूरत नहीं, केवल `pyswisseph` चाहिए। बड़े सिमुलेशन (२ से १० लाख) में कई मिनट लगते हैं।

### फ़ोल्डर

| फ़ोल्डर | क्या है |
|---|---|
| जड़ (root) की `.py` फ़ाइलें | अकेली चलने वाली फ़ाइलें। जिन सहायक फ़ाइलों की ज़रूरत है, उनका कोड फ़ाइल के ऊपर अंदर रखा है। |
| `src/` | वही कोड, अलग-अलग मॉड्यूल में। **बदलाव यहीं करें।** |
| `tools/make_standalone.py` | `src/` से जड़ की अकेली फ़ाइलें दोबारा बनाता है: `python tools/make_standalone.py` |
| `outputs/` | हर फ़ाइल को पूरे सैंपल साइज़ पर चलाने का आउटपुट (`<फ़ाइल का नाम>.txt`) |

सभी सिमुलेशन में `random.seed` तय है, इसलिए दोबारा चलाने पर ठीक यही आउटपुट आता है।

अष्टकूट में गण के अंक Parashara's Light से मिलाए गए हैं: वर देव और वधू मनुष्य हो तो ६, वर मनुष्य और वधू देव हो तो ५। इससे दिनेश-पी का अष्टकूट २५/३६ आता है, जो सॉफ़्टवेयर से मेल खाता है।

## सीमाएँ

- वर-वधू सूची, जैमिनी सूची और मैट्रिक्स लॉक की शर्तें इस जोड़े को देखकर बनाई गई थीं, इसलिए उनकी दुर्लभता कुछ बढ़ी हुई दिख सकती है।
- नवांश लग्न पर टिके नतीजे तभी पक्के हैं जब जन्म-समय ४-५ मिनट तक सही हो।
- दशकूट ४४ के कूट-वार अधिकतम अंक रिपोर्ट के कुल से निकाले गए हैं; गोत्र हमेशा १ माना गया है।
- योनि के अंक मानक १४ x १४ तालिका से हैं (४ समान, ३ मित्र, २ सम, १ शत्रु, ० महाशत्रु)। कुछ पंचांगों की तालिका थोड़ी अलग होती है।
- दशकूट के वश्य में केवल शास्त्रीय वश्य-राशियाँ गिनी गई हैं; दोनों की राशि एक होने पर वश्य नहीं माना गया।
- दिनेश के जन्म की तिथि (३० सितंबर १९८९) ग्रह-स्थितियों से उलटी गणना करके निकाली गई है।
- ये आँकड़े बताते हैं कि संयोग कितने कम बनते हैं। ये वैवाहिक जीवन के फल का प्रमाण नहीं हैं।
